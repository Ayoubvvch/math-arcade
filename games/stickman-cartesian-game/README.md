# Stickman · Orthonormal Cartesian World `(O; i, j)`

عالم رياضيات حيّ داخل معلم متعامد ممنظم `(O; \vec{i}, \vec{j})` تعيش فيه شخصية Stickman مفصلية بالكامل (IK/FK)، وتستطيع الجري، التسلق على محور الأراتيب `x = 0`، السقوط الحر، رسم الدوال `y = f(x)` والتزلّج على مماساتها مع عرض `f'(x)` و`f''(x)` لحظيًا، واجتياز 6 تحديات في إتقان المشتقات.

## 📐 المحرك المشترك (`shared/cartesian-world.js`)
تستعمل اللعبة مكتبات المعلم المتعامد والشخصية المستخرجة داخل مجلد `shared/` ليمكن إعادة استغلالها في ألعاب رياضية مستقبلية:
- `../../shared/cartesian-config.js` — الثوابت الفيزيائية والأبعاد والثيمات (`CARTESIAN_CONFIG`, `CARTESIAN_THEMES`, `cartesianUtils`).
- `../../shared/cartesian-grid.js` — رسم المعلم المتعامد الممنظم `(O; i, j)` والـ orthogonal marker والإسقاطات ومتجهات السرعة (`CoordinateGrid`).
- `../../shared/function-plotter.js` — محلّل صيغ آمن بلا `eval`، رسم المنحنيات والمشتقة `f'(x)` والمماس الحي (`FunctionPlotter`, `compileExpression`, `evalScalar`, `derivAt`, `d2At`).
- `../../shared/cartesian-particles.js` — نظام الجسيمات (`ParticleSystem`).
- `../../shared/cartesian-input.js` — توحيد الكيبورد والكنترولر وأزرار اللمس (`InputManager`).
- `../../shared/stickman-engine.js` — محرك شخصية Stickman بكامل حركاتها وفيزياء التزلّج على الدوال (`Stickman`).
- `../../shared/cartesian-world.js` — نقطة تجميع موحدة + الغلاف الجاهز `CartesianWorld`.

## 🎯 تحديات إتقان المشتقات (6 Trials)
1. **جسر المماس (`tangent-bridge`)**: إنشاء مستقيم مماس يطابق `h(2)` و`h'(2)`.
2. **القمم والقيعان الحرجة (`stationary-points`)**: تحديد نقط انعدام المشتقة `f'(x) = 0`.
3. **نقط الانعطاف والتقعر (`inflection-flip`)**: تحديد نقط انعدام وتغيّر إشارة `f''(x)`.
4. **ركوب منحنى المشتقة (`graph-derivative`)**: استنتاج ورسم `y = h'(x)` للوصول إلى النجمة.
5. **وصلة ناعمة قابلة للاشتقاق C¹ (`smooth-seam`)**: تحقيق الاتصال `C⁰` وتساوي الميل `C¹` لتفادي الانكسار.
6. **حساب القفزة والميل (`launch-calculus`)**: ضبط الارتفاع `f(2)` وميل الإقلاع `f'(2)` للقفز المماسي نحو الهدف.

## 🎮 التحكم
- **المشي / الجري**: `A/D` أو `←/→` (+ `Shift` للجري) أو `Left Stick / D-Pad`
- **القفز والقفز المزدوج**: `Space` أو `W/↑` أو `A / ✕`
- **تسلق محور `x = 0`**: `Q` أو `W/↑` عند المحور
- **التزلّج على المنحنيات `y = f(x)`**: `S` لتسريع الانزلاق المماسي · `S + Space` للنزول عبر المنحنى
- **تثبيت النقط الحرجة / الانعطاف في التحديات**: `B` (أو `Enter`)
- **حركات إضافية**: `E/K/X` (Dash) · `F` (Flip) · `G` (سقوط حر) · `Z / 1 / 2 / 3` (الرقصات) · `R` (العودة للأصل `O(0,0)`)
- **التصوير والعرض**: سحب الفأرة للتحريك · عجلة الفأرة للتكبير/التصغير · `P` الإسقاطات · `V` متجه السرعة · `C` تتبع الكاميرا · `T` تبديل السمة
