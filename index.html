      How to Add a New Math Game

      This console hub is built for zero-build extensibility — any game registered in games.json automatically appears in the PS5 launcher strip.

      Step 1: Create Game Directory

      • Create games/<your-game-slug>/index.html
      • Import ../../shared/gamepad.js, retro-audio.js, math-engine.js

      Step 2: Register in games.json

      {
  "id": "my-game",
  "title": "My Calculus Game",
  "category": "Calculus",
  "difficulty": "Intermediate",
  "difficultyLevel": 2,
  "description": "Short description...",
  "mathConcepts": ["Concept 1", "Concept 2"],
  "controls": ["✕: Action 1", "Left Stick: Move"],
  "path": "games/my-game/index.html",
  "icon": "∫",
  "accentColor": "#00e5ff",
  "status": "ready"
}
